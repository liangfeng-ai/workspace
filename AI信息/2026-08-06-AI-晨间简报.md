# 今日 AI 简报：2026-08-06

## 一句话总结
过去 24 小时没有可核验的“旗舰大模型发布”级事件，今天更重要的是产品落地、模型退役和迁移窗口。对开发者来说，最需要关注的是 Claude 旧模型退役、OpenAI Assistants API / o3 的 8 月下旬停用节点，以及 Google 图像模型 8 月 17 日关闭带来的迁移压力。

## 重点新闻

### 1. Anthropic：Claude Opus 4.1 到达退役日期，API 用户需迁移
- **发布时间 / 生效时间**：页面近期更新；`claude-opus-4-1-20250805` 退役日期为 **2026-08-05**
- **摘要**：Anthropic 的模型生命周期页面显示，`claude-opus-4-1-20250805` 已在 2026-06-05 标记 deprecated，并在 2026-08-05 到达暂定退役日。官方推荐迁移到当前 active 的 Claude Opus / Sonnet / Fable 系列。
- **为什么重要**：如果你的应用、脚本、Agent 或企业工作流仍硬编码旧模型 ID，今天开始可能遇到调用失败或容量限制。应立即检查模型 ID、回归测试输出质量与成本。
- **来源**：[Anthropic Model deprecations](https://platform.claude.com/docs/en/about-claude/model-deprecations)

- **来源**：[ChatGPT Release Notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

### 4. Google Workspace：Gemini / Omni in Vids 的 Scheduled Release 从 8 月 5 日开始
- **发布时间**：原公告 **2026-07-16**；Scheduled Release rollout 从 **2026-08-05** 开始

- **来源**：[Google Workspace Updates: July 2026](https://workspaceupdates.googleblog.com/2026/07/)

### 5. Google Gemini API：旧 Imagen / Gemini Image 模型将在 8 月 17 日关闭
- **发布时间**：公告 **2026-06-15**；关闭时间 **2026-08-17**
- **摘要**：Gemini API changelog 显示，Imagen 4 与 Gemini 3 Image 相关模型将在 2026-08-17 关闭，Google 建议迁移到更新的 Nano Banana / Gemini 图像生成能力。
- **为什么重要**：今天距离关闭窗口已不足两周。任何依赖 `imagen-4.0-*` 或旧 Gemini Image 模型的图片生成、营销素材、设计自动化、视频封面生成流程都应尽快迁移。
- **来源**：[Gemini API Release notes](https://ai.google.dev/gemini-api/docs/changelog)

### 6. OpenAI：Assistants API 8 月 26 日关闭，迁移到 Responses API 的窗口继续收紧
- **发布时间 / 生效时间**：官方文档显示关闭时间 **2026-08-26**
- **摘要**：OpenAI 文档标注 Assistants API 已 deprecated，并将在 2026-08-26 关闭；官方建议迁移到 Responses API。
- **为什么重要**：这是对开发者影响最大的近期平台变化之一。使用 Threads、Runs、Assistants、File Search、Code Interpreter 老接口的产品，需要尽快完成迁移和权限审计。
- **来源**：[OpenAI Assistants API deep dive](https://platform.openai.com/docs/assistants/deep-dive/run-lifecycle%23.webm)

### 7. 腾讯混元 Hy3：面向 WorkBuddy / CodeBuddy 的限免活动已延长至 8 月 5 日并到期

## 值得关注的产品 / 工具

### Claude 当前模型线
- **适合谁**：使用 Anthropic API、Claude Code、企业 Agent 的开发者。
- **能做什么**：代码、文档、长上下文任务、复杂推理。
- **是否值得尝试**：值得。今天重点不是尝鲜，而是检查是否仍调用 `claude-opus-4-1-20250805` 这类旧 ID。

### ChatGPT Work / Codex
- **适合谁**：需要让 AI 处理跨文件、跨应用、数据分析、代码任务的个人和团队。
- **能做什么**：研究、分析、文档生成、任务执行、代码协作。
- **是否值得尝试**：值得。OpenAI 今天的培训安排说明 Work / Codex 是近期主推方向。

### Google Vids + Omni
- **适合谁**：市场、培训、销售、教育、内部沟通团队。
- **能做什么**：用自然语言生成或编辑视频内容，降低视频制作门槛。
- **是否值得尝试**：如果你在 Google Workspace 生态内，值得试用；但注意 EEA、英国、瑞士、Texas、Illinois 等地区限制。

### Gemini 3.6 Flash / 3.5 Flash-Lite
- **适合谁**：构建高频 Agent、自动化、低延迟 API 工作流的开发者。
- **能做什么**：更低成本的代码、规划、子 Agent 调用。
- **是否值得尝试**：值得纳入成本评测，尤其适合作为多 Agent 系统中的便宜执行层。
- **来源**：[Gemini API Release notes](https://ai.google.dev/gemini-api/docs/changelog)

### Qwen / Model Studio
- **适合谁**：国内应用、中文场景、多模态和代码工具开发者。
- **能做什么**：文本、视觉、代码、图像生成、上下文缓存。
- **是否值得尝试**：值得，但今天未看到过去 24 小时内新的高价值一手发布；更应关注已有模型的价格、缓存和生命周期。
- **来源**：[Alibaba Cloud Model Studio Release Notes](https://www.alibabacloud.com/help/en/model-studio/model-release-notes)

## 对我的启发

1. **开发者**：今天应做一次模型 ID 和 API 生命周期审计。重点检查 Claude 旧模型、OpenAI Assistants API、Google 旧图像模型，避免月底前出现生产故障。

2. **个人效率**：ChatGPT Work、Codex、Google Vids 这类工具正在把 AI 从“回答问题”推向“完成工作”。可以优先把重复的研究、数据整理、文档、视频草稿流程交给 Agent 化工具。

3. **创业机会**：模型能力本身的差距正在缩小，机会更多在“迁移工具、成本监控、模型路由、企业权限、Agent 工作流模板”。帮企业安全地从旧 API / 旧模型迁移，是短期明确需求。

4. **产品设计**：不要只做一个聊天框。今天的信号显示，文件、业务系统、视频、代码仓库、日程任务和权限控制，正在成为 AI 产品的标准组件。

5. **成本策略**：把旗舰模型用于规划和关键判断，把 Flash / Lite / Haiku / Coder 类模型用于批量执行，是更现实的 Agent 架构。
